# Научное письмо: материалы по заданиям ПЗ-1…ПЗ-5

Студент: **Запольских Николай**, группа **БПМ-23-РК-1**.

Тема: **восстановление ориентации и траектории кисти по данным акселерометра и гироскопа смартфона с коррекцией дрейфа по остановкам**.

В репозитории лежат только итоговые версии пяти заданий. Черновики, чужие работы и вспомогательные материалы сюда не входят.

## Статья (ПЗ-3)

- `pz3/article.tex` — исходник, 6 страниц, две колонки, 16 источников.
- `pz3/article.pdf` — собранный PDF.
- `pz3/misisarticle.cls` — класс сборника НИТУ «МИСиС».
- `pz3/fonts/` — Liberation Serif и Mono, метрически совместимые с Times New Roman; нужны для кириллицы.
- `pz3/figures/` — схема обработки и траектория до/после коррекции.
- `pz3/code/` — классы приложения и самодостаточный пример коррекции.
- `pz3/Makefile` — локальная сборка.

Локальная сборка:

```bash
cd pz3
make article
# PDF: build/article.pdf
```

Или вручную:

```bash
cd pz3
xelatex -output-directory=build article.tex
xelatex -output-directory=build article.tex
```

Компилятор — **XeLaTeX**. Если используется минимальный TinyTeX, нужен пакет `tex-gyre`:

```bash
tlmgr install tex-gyre
```

В полном TeX Live и в образе GitHub Actions этот пакет уже есть.

## Сборка PDF в GitHub Actions

Workflow лежит в `.github/workflows/build-article.yml`. Он собирает `pz3/article.tex` и выкладывает `pz3/article.pdf` в артефакт `article-pdf`.

После push в ветку `main`:

1. Откройте вкладку **Actions**.
2. Выберите последний запуск **build-article**.
3. Скачайте артефакт **article-pdf**.
